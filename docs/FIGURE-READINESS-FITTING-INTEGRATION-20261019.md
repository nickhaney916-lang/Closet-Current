- Retain main chat's transparent owned-garment cutouts, safe white-matte gate, local mesh-fidelity fallbacks, bounded silhouette recentering, one-pixel hard alpha finishing, four-piece outfit/dress ordering, account-scoped in-memory cache, transient local selfie and safe held-photo recapture.

The proposed minimum masters are **1294×2398** native, preferably **1941×3597**; the current previews meet **zero** production native-resolution sampling cases. No production masters, exact-asset modification/redistribution rights proofs, release/fictional-character provenance, independent visual approval or reviewed pair anchors are present.
- Reproduce exact Work report bytes offline with pinned Pillow and test both existing assets on Android Chromium/iPhone WebKit emulations, screen DPR 1/2/3 and CSS zoom 1/2. The 24 controlled figure tests and full-app browser fitting suite are independent checks, **not actual physical phones**.
- Add an integration contract test binding the runtime's exact two figure filenames and file hashes to Work's evidence. It verifies male/female slot placements remain inside the canonical 647×1199 fitting stage and ensures the current low-resolution figures are **still classified as blocked**, not silently promoted. This does not alter coordinates, original clothing pixels or the application UI.
