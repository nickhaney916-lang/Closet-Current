## New engineering capability

**Read-only real skinned-anatomy profiler** `research/three-d-19/wrist-anatomy-audit.mjs` loads exact hash-pinned CC0 human geometry and the existing licensed, source-bound verified shirt/cuff assembly. It evaluates Three.js `SkinnedMesh.applyBoneTransform` on actual original body vertices, original 3D17 inner cuff facing, and new 3D18 source-neutral hem boundary, with the original named anatomical wrist/forearm bones (`lowerarm01L/R`, `wristL/R`). For each side of both adult figures and actual *source* and *relaxed* poses, it computes sampled nearest Euclidean surface-vertex gap, radial distances to the forearm axis, and signed-relative **axial fraction along the forearm**, with real sample counts. It does **not** move geometry, alter the original photographed shirt, or invent source image pixels.

**Interpretation caveat:** Nearest-sampled-vertex Euclidean distance is **unsigned and is not true cloth-body triangle-intersection clearance**. Actual garment or skin can intersect between sampled vertices, and a pale wedge can remain visible even when nearest sampled points are close. Every record therefore explicitly sets `signedClearance=null`, `bodyTriangleIntersectionValidated=false`, `visualWedgeCount=null`, `collisionValidated=false` and `humanVisualApproval=false`. This does not certify collision-free or photo-realistic clothing. No absolute arbitrary distance is misrepresented as aesthetic PASS.

**Independent matched screenshots:** The exact **unchanged** 3D-18 native Chromium WebGL source benchmark (`scripts/test-three-d-18-browser.mjs`) re-renders actual licensed AJ shirt, neutral pants, female/male human models, 320/390/430 mobile screen widths, matching same-angle before/after 3D18 bridge views (12 genuine GPU screenshots). The new `scripts/build-three-d-19-visual-qa.mjs` builds a **430px eight-panel contact sheet** cropping both wrists for both bodies and both before/after views. This is a deterministic broad crop of the original real browser screenshots (no AI image synthesis or touchups), with an explicitly HOLD review manifest. The source license/source JPEG/PNG have not been modified. It helps find whether the skin sliver was reduced on the *same* camera, not a preferred pose or synthetic figure.
