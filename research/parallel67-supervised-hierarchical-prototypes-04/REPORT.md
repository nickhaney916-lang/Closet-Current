### Starting point: observed improvements and limits
The [verified P67-02 fashion-trained Marqo model](https://github.com/nickhaney916-lang/Closet-Current/pull/896) at exact head `42dd05cb3378fdb103d16408d4751460054d35e9` achieved forced-top1 broad category **12/13** and subtype **8/13** against 13 existing development-exposed public garment originals, but non-clothing ranking **0/3**. Three previous confusions were corrected relative to the generic model; other errors remain. Models are uncalibrated and should not save automatically.

### WHY this milestone exists
Repeating model prompts or weak same-model corroboration cannot reliably distinguish a T-shirt/sweatshirt, blouse/tunic, sneakers/boots, or dresses. A supervised **hierarchical** head trained on actual labeled fashion features is an honest new class of evidence that the prior zero-shot model did not use.

But training data coverage is the gating concern, not the count of automated application tests:
- **Training:** exactly 32 already-annotated, SHAs-verified publicly licensed `benchmark/manifest-reviewed-32.json` original photographs. Types include a few T-shirts, jeans, shorts, skirts, jackets/coats, sneakers and generic Boots and Dress. **There are zero annotated blouse, sweatshirt and non-clothing samples for training**. This prevents a defensible T-shirt-vs-sweatshirt or blouse-vs-tunic specialist or automatic garment/not-garment gate. Generic `Dress` and `Boots` don't establish fine dress or boot subtypes.
- **Evaluation:** exact 16 `benchmark/manifest-holdout-16.json` publicly licensed SHA-checked originals, never included in the 32 source-ID or source-SHA training set. **Critically these were used throughout prior app development and P834/P835/P67-01/02; they are NOT newly independent blind photos.** This is an exploratory, precommitted diagnostic only. Don't tune a model on this set and then claim an independent accuracy estimate.
- The separate 11 `benchmark/manifest-fresh-11.json` originals are NOT mixed into this training or evaluation to preserve a third source partition for later diagnostic expansion; they were also seen in earlier development and are not newly blind.

### Actual implementation
1. `scripts/parallel67-run-hierarchical-real48-04.mjs` loads the exact pinned **Marqo/marqo-fashionSigLIP q8 image encoder**, version `782eaf7a0b95411ac96893d2300d1a61a2bcb757` locally, SHA-verifies each real downloaded original JPEG, extracts image embeddings and never sends the photos to a remote inference service. Processes **32 training** + **16 diagnostic** source images. Never saves photo image bytes or 768-dimensional private embeddings in CI artifacts.
2. `scripts/parallel67-hierarchical-prototypes-04.mjs` fits actual **supervised normalized 768-D prototype/centroid category heads** on training examples and separate within-category subtype heads. Needs at least two genuine examples per trained class and **at least two contrasting trained subtypes within a category** before suggesting a subtype. The learned heads are real data-derived models, not hard-coded category rules or tuned prompt strings. Missing or unsupported fine types produce **review**. Generic `Dress` / `Boots` supervision is kept explicitly coarse, never fabricated into specific dress / boot families. No calibration or automatic wardrobe admission.
3. `scripts/parallel67-compare-hierarchy-04.mjs` downloads the **original successful P67-02 baseline from GitHub Actions #43151861029**, verifies same 16 source IDs, expected human category and type labels, and source manifest SHA, then compares **forced top-1 vs forced top-1** category/subtype gains and losses (including previously correct cases made wrong), non-clothing negatives and unsupported class coverage. Does NOT compare uncalibrated top-1 to existing accepted FashionCLIP coverage as if those denominators matched.
4. `tests/parallel67-supervised-hierarchy-04.test.mjs` rejects fabricated owner/source labels, duplicate source IDs and SHA across data splits, training on evaluated originals, wrong image vector shape/NaN, generic types promoted to fine classes, unsupported subtype pseudo-confidence and negative images presented as automatically saved garments.
5. Full native app tests and a real q8 encoder source run in no-deploy GitHub Actions. Only 6 research/test/CI paths differ from exact fully successful P67-02 parent.
