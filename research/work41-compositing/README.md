# Work 41 — experimental compositing, INCOMPLETE / HOLD

An isolated research renderer composes unmodified `renderPhotoLayers` outputs by drawing bottoms, tops/dresses, then outer layers. It allows dress + outer layer in research, while still refusing dress + top/bottom. Individual item images and contain geometry come from the unchanged current renderer. Optional foreground hands use the two existing humanoid SVG paths, not a redesigned figure. This is not garment-specific occlusion: hands may hide real cuff/fabric and should only be enabled for visual review. No shadow, cutout modification, texture or inferred open/tucked clothing is added.

The existing planner's order places shoes and bottoms before tops/outerwear and rejects dress with any outer layer. The whole humanoid SVG is behind all images: a sleeve can cover hands. Rigid containment does not follow arms or drape. Ordering can fix which of two already-compatible layers is in front; it cannot repair sleeve angles, garment scale, background residue, mannequin parts or a photograph that already contains another garment. Those belong to fit or extraction. Work #332's single-shoe reference guard is not reproduced here: this standalone prototype refuses shoes altogether. Its callers must independently enforce all source/mask, owner and session gates. It is not connected to the live renderer or approval pipeline; it cannot make an unapproved mask safe or allow account access.
