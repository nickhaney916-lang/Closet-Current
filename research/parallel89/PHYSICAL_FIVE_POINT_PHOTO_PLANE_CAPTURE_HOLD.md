# Mission 2 — independent five-point physical photo-plane registration (HOLD)

## What this adds (not physical wearable fit)
The independent research-only `physical-five-point-photo-plane89.mjs` tests a physically measurable, single-planar camera reference. Four measured rectangle corners determine a projective image-to-**reference-plane** map; one independently placed and measured fifth point checks whether that four-corner map is credible. A geometric reference-plane result **cannot** establish the physical volume, camera intrinsics, folded textile shape, body measurements, garment mask/rear, drape, stitching, contact or layered fit.

This expands the two linear ruler intervals in the **existing unmerged P107 #1505** prototype. It does **not** edit P107, its private app context, or its original lease/owner-bound handoff. It is independent, opt-in research logic. No consumer code or private real garment photo is added to a public repository.

## Capture an authentic *personal* garment (not a synthetic or catalog photo)
1. Lay one garment as flat as possible on a rigid surface. Keep its actual edges fully visible. Record whether wrinkles, folds, perspective, occlusions or a visible back make a planar model false. If not flat, **do not assert physical garment-wide mm/pixel**.
2. Use a **rigid flat rectangular measurement target**, visible in the same physical plane as the garment. Measure the rectangle's **actual physical** width and height with a ruler/caliper; do **not** trust print/page/paper nominal dimensions without measuring them. Record units, instrument and uncertainty for both sides. The four corners should be visible and noncollinear.
3. Independently mark a fifth point **inside** the target with physically measured x/y offsets from the top-left (e.g. actual X and Y readings). Record its position uncertainty. It must be a genuinely observed mark, **not** the center calculated from the four corner pixel coordinates or a fifth point manufactured using the transformation.
4. Shoot the **original full-resolution JPEG** from overhead where possible. Save original bytes with EXIF orientation and SHA-256. Record the four actual rectangle-corner pixel coordinates in order: physical upper-left, upper-right, lower-right, lower-left, **as measured in original (not auto-rotated or cropped) pixel space**. Record the independently seen fifth point's actual pixel coordinate and expected measured mm position. Document pixel placement uncertainty. If EXIF orientation is 2–8, explicitly transform to verified original pixels in a separate reviewed process; current research evaluator blocks these.
5. Independently use a tape to measure garment length, full closed circumference (if applicable), and garment waist/chest/hip/sleeve/inseam landmarks. A flat single width is **not** a circumference. Record the garment's front, rear/side photographs as independent source originals when genuinely observed. Physically measure the actual target wearer/garment relationship and actual avatar metric scale before any fitting claim.
6. Keep all owner, photo and wearer records in the **authorized private owner workflow**; do not commit photos, session data or body measurements into GitHub.

## How to interpret
- If reference corners are missing, collinear, cropped, self-crossing, too small, fifth point out of region, EXIF unreviewed, source digest changed or the camera/reference is not planar, the checker says **BLOCKED**.
- If an independent fifth target point materially disagrees with the four-point model after explicit measurement uncertainties, the checker says **BLOCKED_INDEPENDENT_FIFTH_POINT_DISAGREES**. That is a genuine *geometry* falsification and a prompt for a new capture, never a reason to enlarge tolerance until it passes.
- With a synthetic reference, a mathematically consistent map is only **RESEARCH_ONLY_SYNTHETIC_FIVE_POINT_REFERENCE_MATH_PASSED**.
- With human-entered real claims, even a matching mathematical map returns **BLOCKED_REAL_CALIBRATION_INDEPENDENT_ATTESTATION_AND_BODY_REGISTRATION_PENDING**. The code cannot independently verify a physical ruler, an actual garment-plane pose or owner/wearer anatomy from numeric JSON fields. Live ownership, source SHA, current auth lease, external measured reference/device validation, and wearer/avatar size remain **separate** responsibilities.
- The output's homography and local scale samples are **reference-plane-only**; neither an inferred global cloth `mm/pixel` nor a permission to put the shell on an avatar. `consumer3DAdmitted:false`, `originalPhoto2DFallbackRequired:true`, Family Alpha HOLD at every result.
