# Mission 2 — actual measured garment-to-wearer/avatar metric fitting gate (research only, HOLD)

This is the **next engineering prerequisite**, not a completed real fitted garment. It can combine independent physical measurements from a particular wearer/garment with the actual licensed 163-bone rig geometry, and identify likely/definite size mismatch **without** manufacturing a 3D mesh or claiming contact/cloth physics.

## Measurements required to establish a real fit
1. **Owner-authorized original garment photo:** one byte-preserved original JPEG with SHA-256 and source revision/ownership validation. Capture a separately physically measured fiducial reference with a fifth holdout as documented in [PR #1596](https://github.com/nickhaney916-lang/Closet-Current/pull/1596). Keep the actual source private; GitHub can run only synthetic/public fixture data.
2. **Real wearer metric registration:** select the actual wearer who will fit the garment. Measure **three different** named anatomical *spans* on that specific person: head-to-foot (height), shoulder span, and matching torso-landmark span as appropriate. The licensed 163-bone mesh must have independently identified corresponding true mesh coordinates for exactly the same anatomical landmark endpoints, **from the original source geometry at a documented common reference pose**. Two independently measured spans constrain physical millimetres per native rig unit; the third measured span MUST be a held-out independent falsification check, not reused as another fitted coefficient. If anatomical landmarks cannot be matched, do not promote the scale.
3. **Real garment measurements:** directly measure closed garment and wearer body circumferences with tape and record instrument/uncertainty. For skirt/trousers, measured waist and hip at physically corresponding heights; top/jacket, chest and waist; dress, chest, waist and hip. A flat two-dimensional width is NOT a closed circumference. A museum object's photographed bottom width is NOT automatically an observed physical hip circumference or wearer dimension.
4. **Actual camera and sewn geometry:** a real physically measured in-photo planar target, reviewed garment front boundaries and seams, observed original rear and side with their SHA, actual garment pattern/side depth and attachment locations, plus independently calibrated real camera/rig spatial pose and verified wearer shape. The measured body-scale and circumference check alone is **not** geometry registration to an original photo shell.
5. **Verified mechanical fit evidence:** valid source specimen stretch/shear/bend/friction, real body-surface full-index contact and continuous motion with measured cloth clearance, human reviews and real device acceptance. Existing [physical-fit contact/material research #1495](https://github.com/nickhaney916-lang/Closet-Current/pull/1495) and [source-locked handoff #1514](https://github.com/nickhaney916-lang/Closet-Current/pull/1514) are NOT duplicated or bypassed.

## What the implementation calculates
- Inputs: trusted original SHA/identity; independently checked exact licensed male/female 163-bone GLB source; separately authenticated owner measurement revision; two physical 3D landmark spans with nonzero metric uncertainty; independent held-out third span; direct closed anatomical garment/body circumference pairs with uncertainty.
- Two anchor intervals of mm per native rig unit must **overlap**. The third independently measured anatomical span must intersect that overlap too. The algorithm outputs only the metric interval justified by the first two anchors. Contradiction blocks further fitting.
- For each matching body/garment section, it calculates a **conservative ease interval**:
  `minEase=(garmentMm-garmentUncertainty)-(bodyMm+bodyUncertainty)`
  `maxEase=(garmentMm+garmentUncertainty)-(bodyMm-bodyUncertainty)`.
- If max ease is below zero at any location, it emits **BLOCKED_MEASURED_GARMENT_DIMENSIONAL_DEFICIT**. This means nonstretching dimensional clearance is impossible there; it does **not** prove a stretchy garment cannot fit. If minimum ease is positive, the dimension is compatible but no drape/contact/closure is proven. If interval crosses zero, size evidence is uncertain.
- At every result, regardless of claims: `consumer3DAdmitted:false`, `garmentToLicensedRigMeshFitted:false`, `actualOwnerMeasuredPhysicalFitCertified:false`, original-photo 2D fallback and Family Alpha HOLD.

## Genuine original Met model remains unfit
Even though the original [Met part A real physical object measurements](https://github.com/nickhaney916-lang/Closet-Current/pull/1595) and genuine 163-bone mesh are source verified, the research engine has **no actual specimen-matched wearer's head/shoulder/torso tape dimensions, matching original rig landmark endpoints, full closed original physical skirt waist/hip circumferences or wearer shape**. Thus both original male/female native Chromium/WebKit tests MUST reject at `BLOCKED_NO_REAL_GARMENT_OR_WEARER_MEASUREMENTS` without importing a generic 175cm mannequin, inventing a corresponding user's height, or treating rig `2/size.y` normalization as an actual real-world wearer scale.

## Practical privacy and verification
- Do not place actual wearer/body measurements, private photos, owner IDs, authentication leases, health data or contact information in this public research repository, CI test logs or Mission Control issue. Only anonymous synthetic test values belong in the committed example.
- Use `node --test tests/m2-measured-wearer-rig-fit-gate.test.mjs` for adversarial synthetic measured fit, uncertain ease, size deficit, invalid body anchors, false ownership, altered original source and missing real measurements. The branch-scoped no-deploy workflow runs unchanged app build/full privacy/security suite plus exact original source and both Chromium/WebKit male/female real rigs.
- Need actual separately captured, privately authenticated owner/garment/rig data before saying physical garment-to-body fit has been achieved. The software cannot create that observation automatically from a single arbitrary photo.
