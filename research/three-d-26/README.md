## 3D-26 work, not a new photographed dress algorithm

- Keep actual original SHA-verified male/female GLB bodies, original JPEG, source-RGB PNG, V trim, 3mm armhole edge and all existing skinned dress and shirt geometry exactly as in PR430.
- Add a **live shader uniform** to the existing *underlying CC0 mannequin* material. It is enabled **only while** the active outfit is a `commons-0053` source-verified, reviewed, separately skinned 3D24 anatomical dress (and mode=dress). It is not enabled for shirt, shirt+pants, basewear-only, failed review or `?dressAnatomy=before` fallback. Outfit controller remains unchanged and retains atomic rollback.
- When enabled, fade the dark-green source-free training-top color **only at upper lateral armhole wings** (about rest Y 1.39–1.51, |X| 0.135–0.205) and bounded **V-neck upper center** (Y 1.49–1.60), revealing the original *opaque neutral mannequin clay material* that was always beneath the separate skinned dress. This is a privacy-preserving material/color adjustment, not a synthetic user face/skin texture, partial transparency or unclothed user depiction.
- Preserve the neutral opaque basewear color across the **central chest, lower torso and pelvis**, leaving shorts unchanged even when a dress is shown. Removing the dress, changing the figure, or switching to AJ shirt+pants synchronously restores the exact previous basewear shader color. Importantly, no original CC0 mesh positions, body skin weights, source photo, garment cutout, garment material, dressed-person image or user data changes.
- `?dressBasewear=before` disables **only this garment-specific neutral mannequin opening treatment** for genuine before/after comparison. Other existing 3D23/24 toggles remain independent and working. It defaults ON only as a preview; never asserts real clothing fit or owner approval.

This is deliberately scoped: the green exposed material was caused by the **underlying mannequin shader**, not by poorly isolated source fabric or the actual dress. Fixing it by changing source image colors, hiding the original 3D dress edges, repainting clothing, inventing measurements, or flattening a screenshot would be wrong. The original CG body mesh is itself a local, reusable anatomical A-pose research model, not a photograph of a person.
