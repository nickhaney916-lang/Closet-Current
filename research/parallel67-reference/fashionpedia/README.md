# Human-annotated Fashionpedia validation reference

This is a small public reference subset for genuine instance-mask evaluation. Fashionpedia's authors describe mask annotation by trained crowd workers, with supervisor and author review, and attribute annotation by fashion experts. These masks were created independently of this assignment and are copied without relabeling. See the [original paper](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123460307.pdf), section 3.2, and [official dataset repository](https://github.com/cvdfoundation/fashionpedia).

The frozen subset contains **8 images and 38 human object instances**: three dress masks, three merged top/T-shirt/sweatshirt masks, one merged shirt/blouse mask, four pants masks, one shorts mask, fourteen shoe masks, and twelve other apparel/accessory masks. One otherwise permissively licensed image containing RLE masks was excluded before inference to keep this reference polygon-only; `selection-audit.json` records the selection.

**This is not sealed novel acceptance.** It comes from the official public `val2020` split. Pretrained-model exposure is unknown. The small license-screened sample is not representative of phone captures. No inference was run during selection or collection. Source labels collapse `top, t-shirt, sweatshirt` and `shirt, blouse`; they cannot demonstrate T-shirt-versus-sweatshirt or blouse-versus-tunic accuracy. `shoe` also cannot demonstrate sneaker-versus-boot accuracy. No primary-color labels are provided.

## Separate annotation and image permissions

The [official terms](https://fashionpedia.github.io/home/data_license.html) license annotations and ontology under **CC BY 4.0** and explicitly leave image rights with their owners. Attribution: **Fashionpedia Consortium, Fashionpedia validation 2020 instance segmentation annotations**, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes: selection of a subset and exclusion of garment-part categories 27 and above; original instance coordinates, class IDs, areas and bounding boxes remain unchanged.

Only images carrying **CC BY 2.0** in the official annotation file *and* a matching current Flickr primary-page JSON-LD license with a named creator were selected. Each row preserves creator, primary page, license URL, current page checksum and dataset metadata. Unavailable or unverifiable primary pages are recorded as excluded in `license-selection-receipts.json`. Selection did not rely on annotation permission to infer photo permission. Reuse must retain each photograph's named creator, source page and [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/) attribution. License receipts do not imply model-training or model-release approval beyond the source terms.

## Reproduction and evaluation

`manifest.json` and `manifest.sha256` freeze the selected image IDs, JPEG SHA-256 values, official annotation-file checksum, official ZIP checksum, per-image permission receipts and human polygons. `python research/parallel67-reference/fashionpedia/download_reference.py` recovers exact JPEG bytes from the pinned official archive and fails on any checksum change. The official combined `val_test2020.zip` stores both splits under the `test/` archive directory; the split designation here comes from the official validation annotation IDs, not that directory name. These are unmodified **official dataset JPEGs**; no claim is made that they are full-resolution camera originals or byte-identical to a publisher's current Flickr download.

For object-instance evaluation use categories **0–26**, polygon unions per annotation, and one-to-one matching at an explicit IoU threshold (e.g. 0.5). Each separately annotated shoe remains one instance. Do not treat garment-part categories such as collar/sleeve as separate clothing objects. Do not report unavailable fine subtype/color targets as passed. No private family photographs, accounts, uploads, deployments or model inference were used.
