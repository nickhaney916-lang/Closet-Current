## Original-source high-clarity rendering improvement

The original research showroom caps pixel ratio at 1.5 even on high-DPR phones, and original photographic shirt and denim samplers have no anisotropic sharpness override. This can visually soften verified source pixels and suppress fine denim texture on a small angled 3D canvas.

New module `crisp-original-source-rendering.mjs` is **presentation-only**. It optionally renders at **2 physical WebGL pixels per CSS pixel** (hard cap 2×), preserving the same mobile layout. After the original, hash-verified, independently reviewed shirt and denim have passed their owner-review gates, it configures **only the two exact original shader photo uniforms** `uPhoto` and `uPantsOriginalPhoto` to use full original image dimensions, true sRGB, standard linear interpolation with original-resolution mipmaps and renderer-supported anisotropic sampling (max 8). Shader code for source pixel projection, alpha provenance, front/back privacy, neutral side/rear fabric, body contact and photograph color identity is **never rewritten or bypassed**. No source JPG/PNG byte edits, scaling, recoloring, generated texture, fake printed wrinkles or paid model calls. Original 3D56 pose-generated real garment mesh position/normals and shoulder/cuff sewn geometry are untouched. Original 2D outfit board unchanged.

The feature is **OFF by default**; the two original licensed source photo demos opt in only with `crisp58=after` on top of the preceding original-garment research flags (`move56=after` etc). Do not switch the main app, production, alpha, staging or user wardrobe preview defaults.
