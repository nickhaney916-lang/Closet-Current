`scripts/family-alpha-evidence-gate-18.mjs` uses a **read-only** GitHub API token to GET issue #255, each actual PR and dedicated Actions run. Its checks require the same repository, original PR number, exact pinned current head, an open draft not merged, and success from that exact head's dedicated NO DEPLOY workflow. If technical CI green but science failed, it explicitly reports `TECHNICAL_PASS_SCIENTIFIC_FAIL`. Missing or moved evidence fails closed.
