## Evidence-backed reason for second candidate
The genuine independent generic [Google SigLIP](https://huggingface.co/google/siglip-base-patch16-224) run ranked broad category correctly on **10/13** historically used garments, subtypes on **4/13**, and non-clothing **0/3**. Still got T-shirt→Sweatshirt, both blouse→Tunic and one sneakers→Ankle boots; both dresses incorrect. Sigmoid top1 is **not** acceptance or certainty; automatically saving the raw top-ranked guess is forbidden.

This new candidate is [Marqo/marqo-fashionSigLIP](https://huggingface.co/Marqo/marqo-fashionSigLIP) (Apache-2.0; ONNX Transformers.js format), **fine-tuned for fashion e-commerce categories, materials, style and details**, not merely another crop of the same model. Exact model revision `782eaf7a0b95411ac96893d2300d1a61a2bcb757`, published **after** ONNX browser support was added. Quantized `q8` CPU, actual local original JPEG inference, no hosted image recognition and no cloud writes. **Marqo's ONNX repo exposes separate `text_model_quantized.onnx` and `vision_model_quantized.onnx`, not the combined `model_quantized.onnx` expected by a generic pipeline.** The experimental driver explicitly uses `SiglipTextModel` and `SiglipVisionModel` and ranks normalized pooler-embedding cosine similarities. These ranks are **not SigLIP calibrated sigmoid scores** and cannot authorize automatic closet admission. Model weights downloaded from Hugging Face, excluded from GitHub artifacts.
