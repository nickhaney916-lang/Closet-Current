# CLOSET CURRENT — PRIORITY 3D-69

## Actual saved-clothing index → verified source photo → genuine anatomical 3D garment display and swap (research only)

**Starting code:** 3D68 draft PR #479 head `9b958c6fbef87d7828d37f4fef9a07d5a7946d9a` with category-safe, account-bound saved-closet metadata bridge. **Real 3D base:** verified 3D64 [PR #475](https://github.com/nickhaney916-lang/Closet-Current/pull/475). **Other stream:** original 3D66 fabric gravity drape [PR #477](https://github.com/nickhaney916-lang/Closet-Current/pull/477) isolated and not merged.

### Priority
Prove that a trustworthy, categorized item identity can select a **REAL separately skinned photographed source garment** on the actual male and female anatomical humanoids, that the user can **rotate the actual 3D figure 360° and swap a real second garment** without confusing original source hashes, and that arbitrary user photos never silently become fabricated 3D wearables.

### Implemented
- `sha-verified-original-garment-sources.mjs`: exact, SHA-256 byte verified **original photographed Armani Jeans shirt** (Commons `commons-0003`), two **independently photographed jeans fronts**, alpha cutouts, provenance and intact visible RGB pixels. Both denim licensed sources and original shirt use their pinned public-source manifest and full raw image byte hash. All colors shown at unknown sides/back are neutral derived from real photo, **NOT fabricated back pockets, seams, logos or photos**. Only exact original-source loader grants a private WeakSet source capability to the actual 3D rendering binder; synthetic booleans or spoofed hashes alone do not pass.
- `index-to-real-garment-viewer.mjs`: matches 3D68's category-verified `top/bottom` source SHA and original source ID against independently verified public benchmark source candidates; correct anatomical 3D slot, original photo provenance, exact licensed shirt and denim source, runtime authenticated generation and genuine 163-bone loaded figure. Uses the existing `showroom.applyOutfit('shirt-pants', ...)` to generate genuine **independent skinned shirt and pants surface meshes**, not screenshots or a layered static image. Keeps actual original decoded photo pixels in a private WeakMap, not in index return object or any log.
- `index.html` and `index-to-real-garment-demo.mjs`: standalone local original 3D source research preview, full touch 360 camera, male/female, source index selection, independent original photographed shirt, PUBLIC DOMAIN or CC BY-SA denim swapped from existing indexed metadata IDs, reset/clear. It **explicitly discloses** that this is a licensed source research fixture, NOT a customer's own wardrobe.
- `tests/three-d-69-indexed-photo-real-3d.test.mjs`: validates exact Commons SHA/permissions, no spoofed source object or fake buyer image, missing/unsupported 3D fallback, no account data/media leakage, no invented back/garment geometry.
- `scripts/test-three-d-69-real-source-index-browser.mjs`: real original source 320/390 Chromium WebGL male/female with original 3D shirt + two source-correct jeans swapped on each figure, genuine front/side/back/full-360 screenshots, SHA and triangle/skinning/inventory slot and source-pixel comparisons. **20 genuine images** expected if exact-head dedicated no-deploy workflow passes. All browser source images remain open/public licensed.
- `.github/workflows/three-d-69-source-true-index-to-3d-no-deploy.yml`: source SHA/locked-asset, strict ancestor and allowed-path white list; never production, staging, accounts, billing, private family images, Drive Duel, or deployment.

### Boundaries
This connects **a trusted indexed source** to an independently verified source-specific 3D garment. It is **NOT** universal realistic new photo-to-3D garment reconstruction and does not claim user-family photos have been turned into fitted fabric. The current garment engine has only a few vetted exemplar sources, and manual source fit/provenance inspection is still needed for new wardrobe garments. Clothing recognition/auto categories and saved look persistence remain in existing app; no production auth wiring in this branch. Continuous/swept collision, independent aesthetic 10/10 human review, actual Android/iPhone physical phone evidence and family testing remain unapproved, **Family Alpha #255 HOLD**.

**10/10** is a product aspiration, NOT a measured rating against competitors; elite recognition/category review and practical 3D garment swapping are the indivisible experience.
