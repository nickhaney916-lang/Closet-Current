A calculated SHA-256 and perceptual dHash are stored only as public source metadata. Original JPEG/PNG/WebP bytes stay in CI memory and are **never committed, uploaded as artifacts, or handed to model inference**. Commons license metadata, CC license URL, artist and source file page are recorded, but **subject releases, moral/privacy rights, commercial use, physical object identity and actual license compliance need independent legal/curator approval**.
- `exposedSources883` joins both historical 48/59 etc model-exposed photo manifests with the frozen **32 earlier publicly exposed P75 candidate receipts**, forbids repeat Commons page, exact SHA, near-perceptual duplicate or suspected same-publisher original series. It never silently claims two different photos show unique physical garments.
- All new discoveries are `split:'quarantine'`, `photoContent:'unreviewed'`, `rightsReview:'manual-review-required'`, `sourceGroupApproved:false`, `garmentHumanVerified:false`, `modelScored:false`, `labelsPublic:false`. No train, dev, or blind split promotion. Current queries and public source URLs are exposed forever; **these sources must never be used as untouched independent sealed blind evaluation**.
- The outcome is numeric machine-verified **additional public candidate originals**, not a count of real garments or human annotations. Never infer category, subtype, color, pattern or wardrobe unit from filenames, query family or pretrained models. Only an externally approved curator and two distinct independently vetted humans, working on new unexposed sources, can create the actual blinded 60-source acceptance suite.
