## What this milestone specifically does (and does NOT do)

This milestone connects a rectangle generated by actual **automated Chromium and WebKit mouse gestures** on the *genuine native Closet Current Adjust screen* (P800 original SHA-verified source rectangle, P798 original source point, P803 user-correctable unverified local mask) to the **actual immutable SAM2.1 Hiera-tiny ONNX encoder/decoder** established in P799.

- The two browser engines draw a rectangle on the genuine CC BY 4.0 original photograph **commons-0053**, its immutable JPEG SHA matches `benchmark/locked-photo-sources.json`. Their source-pixel rectangle and interior original-pixel seed point are captured from the actual native Adjust control, not from a publisher mask, crop, or calculated oracle ground-truth polygon. The browser gestures are performed by **Playwright automation, NOT an independently verified human owner**.
- The real model is run on the original pixels in a **GitHub Linux CPU research worker**, not in the mobile app or on a consumer iPhone/Android. It receives the original public image, captured browser box `[x0,y0,x1,y1]` and seed point `[x,y]`. Reuses the identical P799 pinned model weights, SHA-256 checks, 1 MiB streaming downloads and preprocessing.
- Two SAM2 ONNX decoder variants run separately **for both native browser inputs**: `box` (SAM2 labels `[2,3]`) and `pointBox` (`[1,2,3]`). Four true decoded original-image mask predictions and source-resolution binary PNG masks are generated for visual comparison with source attribution. The model's own quality estimates are NOT independently measured mask IoU.
- No publisher human mask for this source was used to construct any point/box, no source annotation mask is supplied to the model, and **no independent human blind ground-truth quality score** is available for these four predictions. This is a real **input-to-model integration/provenance proof**, not a product accuracy rate, not a held-out benchmark, and not proof a real person used the UI.
- No customer/owner image is uploaded to GitHub; the source is an already publicly licensed SHA-registered test fixture. No camera/closet photo bytes are sent to an external model. Original user JPEG and local corrections stay unchanged in the app. No remote user inference path exists. **Masks from the model are not rendered in native Adjust and not available for private owner approval or storage yet.** The existing 512x512 P802/P803 color preview is still color-based.
- Owner/draft source identity and permissions remain unchanged. No private wardrobe, production, staging, authentication, cloud policies, 3D or release files touched.
