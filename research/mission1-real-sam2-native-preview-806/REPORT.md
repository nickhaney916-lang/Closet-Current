# Closet Current Mission 1 P806 — REAL archived SAM2 original mask displayed in native Adjust

**FAMILY ALPHA HOLD #255 — DRAFT, UNMERGED, UNDEPLOYED.**
This is an experimental research-only bridge from a truly executed **P804 Linux ONNX** model result to the native owner original-image review surface. It does **not** run SAM2 live on a user's phone or upload a private owner photograph to a remote server.

Model predicted confidence is **NOT independently verified human IoU**. Linux high-water peak was 1,250.86 MiB, so the model is emphatically NOT accepted for consumer on-device memory.

The four model PNG binary masks are retrieved unchanged from P804's exact GitHub Actions artifact #13818138833, not generated from color heuristics, synthetic masks or unverified user uploads.
- For each native browser P804 original JPEG gesture only, import the **immutable point+box mask**. Chromium source box `[360,426,1589,2530]`, point `[955,1434]`, model PNG SHA `f8c50688b5932ae8c879b24ea638ade7994b3c1563b501c93d576c7236cb1bf9`. - Only if **both original owner source SHA-verified P798 point and P800 source rectangle** match these exactly, a research-only enabled button can load the already executed model's immutable PNG. The original JPEG source bytes are rehashed before access. The model PNG is verified by **WebCrypto SHA-256 before any display**, then source dimensions checked and resampled into an ephemeral overlay capped at 512×512 pixels. For any changed owner, photo, box, point or revoked review lease, fail closed and discard.
- To avoid exposing the original source, the test injects only a public artifact reference as an already-in-memory callback **before** native Adjust opens. It never sends owner photo bytes through the callback. The app is not outfitted with a model runtime and cannot accept any other owner's photo SHA. User/private JPEGs must never go to the model artifacts action or an external inference API.

P802/P803 color preview and P806 real-model replay are **mutually exclusive overlays**; both are optional and always discarded without changing category, subtype, color, saved closet, draft, cloud, owner review, or original JPEG. No automatic cutout or model mask approval exists.

## Honest acceptance conditions

An exact final-head CI run must prove (a) strict seven path research-only diff from P805, (b) full Node tests and native build, (c) hostile owner/source/mask forgery tests, (d) archived P804 **actual** PNG SHA before acceptance, and (e) live automated Chromium and WebKit native review of the genuine public original JPEG, rectangle, point, temporary correction/discard, **P804 actual model mask overlay**, manual fixture review and private fixture IndexedDB save. Screenshots must display the actual P804 learned mask and continue to require human labels/approval. Browser actors are Playwright, **not actual independently verified human reviewers**. Real mobile memory, physical Android/iPhone, true signed cloud and private photo inference are not validated.

## Open blockers

This proves *only* that an actual already-computed SAM2 model image can be source-bound, visualized and safely discarded in the real UI. It **does not** provide real private-owner original on-device learned mask generation, human-polygons/IoU, general instance boundary accuracy, actual hand correction of the SAM2 (rather than color) overlay, category/subtype/color recognition or four-person Family Alpha acceptance. Future work: device-safe smaller original photo model, source-bound review/brush/persist after explicit human approval; separately validated training-disjoint blinded image corpus and physical mobile/hosted RLS privacy. Issue #255 remains open.
