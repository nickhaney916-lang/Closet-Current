These 59 public, licensed Wikimedia Commons photographs are the exact validated inputs used for the 32-photo, independent holdout and fresh-photo benchmarks, including the six display fixtures. They are stored with the repository so test runs do not depend on expiring artifacts or external thumbnail rate limits. The downloader verifies each SHA-256 before use. Attribution, author, original source and license for every image are recorded in ../locked-photo-sources.json. No private wardrobe photographs are included.
