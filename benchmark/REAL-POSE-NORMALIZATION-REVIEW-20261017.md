# Real-photo derived garment normalization evaluation — October 17 2026

The category-aware straightening model is intentionally limited to high-confidence isolated studio garments. It is **not generative AI** and cannot unfold folded clothing or restore missing 10% of a sleeve or trouser hem.

Benchmark four previously licensed and SHA-256-verified real photographs: orange shorts, museum jacket, standalone jeans and sneaker. For each, create a before/after display comparison using original bytes and the current axis gate. Report cases that are NOT straightened as explicit no-ops; do not silently label identical previews "better".

The algorithm changes only the ephemeral closet tile. Captured source image, segmentation, classification, colors, account records, cloud backup, and virtual try-on source remain unchanged. Real phone speed/quality and canonical folded-to-unfolded garment quality have not been measured. Review before enabling any generative fabric synthesis.
